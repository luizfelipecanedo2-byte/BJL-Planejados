## 🚀 Como retomar o projeto:
1.  Abra esta pasta no VS Code.
2.  Abra o terminal (Ctrl + J ou Terminal > New Terminal).
3.  Digite: `npm run dev`
4.  Acesse: `http://localhost:8080` (ou a porta que o terminal indicar).

**Até logo!** 👋
